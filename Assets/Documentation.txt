CONFIGURATION DATA:

This scriptable includes two type of information the first one is how much of the value to be for the module to consider it satisfied. For example, water is considered satisfied at range of 10.
The second information is related to how randomly the values will be assigned initially like for each module, the value will be randomly chosen between these ranges.

All attributes have models except health and yield projection so these attributes will be taken from available modules (i.e. climate, energy, irrigation & nutrient).
The formulaes for these calculations are simple as when optimizing, we are setting each modules value to it's satisfied value (eg. water to 10) but for health and yield, we are basically dividing the satisfied value to the numbers of moduels available so we get the satisfied value collectively.


CROPBED DATA:
Each cropbed has it's own unique data that is hardcoded (for now) some of the cropbeds are already satisfied in some attributes and needs optimizing in some attributes.

GAMEPLAY
- Healthy (green) beds grow over ConfigurationData.growthSeconds. When grown, the prompt becomes "[E] Harvest".
- Harvest kg = yield projection x harvestKgPerYieldPoint x crop yieldFactor.
- Esc / Tab closes panels. H = help. L = Arabic/English.

DATA
- Bed values now come from crop_profiles.json (key = GreenhouseName/CropbedName). Values match the scene.
  Turn off with ConfigurationData.useCropProfilesFile to use the inspector values again.
- Bed value = bed's own value + sum of the greenhouse modules (if the bed's own value is already satisfied it is kept).
- Modules are copied at runtime, so Play mode no longer overwrites the Module .asset files.

FARMING SIM LAYER (chat #0 of the Chat Splitter plan)
Architecture: Base/GameEvents.cs is an event bus (Observer pattern). Gameplay raises events
(WellStarted, ModuleOptimized, Harvested, CargoLoaded, Delivered, UpgradeBought, ProductsCollected...);
Missions, Economy, HUD and FeedbackFX only listen. GameManager auto-creates every system at scene load.
--- Managers/EconomyManager.cs  Resources/Data/economy.json: goods + prices (SAR), animals, feed. Money, farm storage,
    truck capacity and growth upgrades. Starts with 500 SAR.
--- Managers/MissionManager.cs  Resources/Data/missions.json: 14-mission chain with rewards.
--- Vehicle/FarmTruck.cs        Drivable truck (E in/out, WASD, Space brake, R reset). Ground-following arcade physics.
--- Vehicle/VehicleSpawner.cs   Builds truck + green loading bay near the player start, animal pen + farm shop,
    and a gold market pad (with a shop) ~120 m away. Place empty objects named TruckSpawn / AnimalPenSpot /
    MarketSpot in the scene to move them. The truck ignores collisions with objects named "*Fence*".
--- Farming/AnimalPen.cs, FarmAnimal.cs, PenCrate.cs  Chickens, sheep, cows eat feed and make eggs, wool, milk;
    collect at the crate; products go to storage and are sold with the truck.
--- UI/ShopUI.cs + Farming/ShopStall.cs  Shop: feed, animals, upgrades (keys 1-9 or click).
--- Graphics/GraphicsEnhancer.cs  Post-processing (ACES, bloom, grading, vignette), SMAA/MSAA, shadows. G = High/Low.
--- Graphics/FeedbackFX.cs  Floating +kg / +SAR text and harvest pop.
--- Helper/Build.cs  Placeholder geometry. Drop a prefab at Resources/Models/Truck, ShopStall, cow, sheep or chicken
    (e.g. free CC0 Quaternius / Kenney models) and it is used instead of the placeholder automatically.
Keys: P pause (Backspace there = new game), G graphics, H help, L language, T training.
